# Switchback Requirements Matrix

> 状态：v0.3 需求细化草案。
>
> 本文把 `REQUIREMTENTS.md` 的叙述性需求拆成可评审条目。优先级含义：P0 是最小闭环必需，P1 是平台可用性和知识闭环，P2 是规模化治理与体验增强。

## Decision Frame

Switchback 的目标函数不是“让 Agent 尽可能自主”，而是“在公司内部权限、审计和交付约束下，把需求稳定转成可追踪产物”。因此 P0 优先级按以下顺序排序：

1. 任务是否能被结构化、异步执行和追踪。
2. Worker 是否在隔离边界内产出可审计 Trace 和 Artifact。
3. 用户是否能看到可理解进度和结果。
4. 长期 Truth 是否有证据、权限、置信度和生命周期。

## Non-Functional Requirements

| ID | Priority | Requirement | Acceptance Criteria | Risk If Ignored |
| --- | --- | --- | --- | --- |
| N-001 | P0 | 所有跨模块命令和事件 MUST 支持幂等、单 owner 流内顺序和稳定 Timeline。 | event/idempotency key 去重；stream sequence 排序与 gap repair；同序号冲突隔离；TimelineCursor append-only；时间戳不作为顺序依据。 | 重复执行、状态回退、时间线漏项或重复扣费。 |
| N-002 | P0 | Worker runtime MUST 默认最小权限，同时避免对沙箱内常规动作反复审批。 | 普通文件/命令/测试/patch/report 自动执行；新增外部鉴权、跨沙箱、生产写和未授权安装需要审批；ApprovalGrant 支持 once/session 限定作用域，waiting_user 暂停 idle 但不暂停 absolute lifetime。 | 要么越权，要么审批噪声使 Agent 无法工作。 |
| N-003 | P0 | Trace、Artifact、Truth MUST 保留来源、权限和生命周期状态。 | 默认 hot 30d/warm 180d/cold 长期且不自动删除；tenant/workspace Membership/ACL 隔离；quarantine/delete 可恢复或幂等收敛；source_deleted 可解释。 | 无法排障/演进、数据泄漏、成本失控或永久无法纠错。 |
| N-004 | P0 | Task、ScheduledCommand、控制通道和 Runtime MUST 可恢复。 | Task commit/response、Outbox relay、scheduled-command lease 和 Worker ACK 丢失均幂等收敛；Heartbeat 使用服务端 receive time/sequence；45s suspect、90s unhealthy；每个 incident 自动重建一次并 fencing 旧 generation/epoch；恢复失败进入 waiting_user。 | 容器泄漏、任务卡死、重复 Transition/WorkerRun、crash loop、split-brain 写入或上下文丢失。 |
| N-005 | P1 | Prompt/context 编译 MUST 有预算控制。 | 每次 ContextPack 记录 token 预算、优先级和 dropped items。 | 成本不可控、上下文污染、响应变慢。 |
| N-006 | P1 | EventCenter MUST 区分内部观测事件和用户可见事件。 | 用户不会收到内部重试、密钥、模型原文等噪声或敏感内容。 | 用户体验差或敏感信息外泄。 |
| N-007 | P1 | 模型调用 MUST 可审计、可限流、可降级。 | LLMProxy 记录 provider、model、route policy、usage、error class。 | 成本失控、故障时不可降级。 |
| N-008 | P2 | 核心协议 MUST 版本化并兼容演进。 | schema_version 存在；breaking changes 通过 OpenSpec/ADR 评审。 | 多模块同步升级困难。 |
| N-009 | P0 | 平台已知 Secret MUST 与通用 Trace 内容分开治理。 | 通用 DLP 可后置，但平台签发/已知 Token 在 Trace、Langfuse、Artifact、用户进度和持久 CLI 输出前确定性剔除；root/refresh secret 不进入 Worker。 | 受管 B2 把短 Token 暴露给 Agent 后形成可避免的持久泄漏。 |
